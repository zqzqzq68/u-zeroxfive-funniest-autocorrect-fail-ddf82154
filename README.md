A program that writes one line under 200 characters that reads as a hilarious autocorrect fail — a work message where "annual contract" came out as "anal contract" — and nothing else.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
cat /tmp/out/entry.txt
```

The program is deterministic: it writes the same fixed line on every run, so two runs always produce the same `entry.txt`.
